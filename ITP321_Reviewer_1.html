Common Exam Traps
These are the most frequently wrong answers
write.csv() ≠ read.csv() — write.csv() creates/exports a CSV. read.csv() reads/imports one. The question says "used to read" → that's FALSE.
Single backslash in R paths is WRONG — setwd("C:\web\Sample") is invalid. Use setwd("C:/web/Sample") or setwd("C:\\web\\Sample").
The > symbol at the start of R console is a prompt, not part of your script. Any script starting with > is NOT accepted as written.
while loop runs while TRUE, not false. If condition is always TRUE → infinite loop.
repeat loop has NO condition in its header. It needs break inside to stop.
User-defined ≠ built-in — Functions you write yourself = user-defined. print(), sum() etc = built-in (in-built).
grepl is NOT an Excel package — grepl is a pattern matching function. Excel packages = XLConnect, gdata, xlsx.
$ sign accesses columns — data$salary, not @, #, &, or *.

CSV — Comma Separated Values
Questions 1, 13, 16, 17, 28, 31, 35, 43

What is CSV?

CSV (Comma Separated Values) is a plain-text file format that stores tabular data. Each row is a line, and each value is separated by a comma. It can be created in Notepad, opened in Excel, and read/written in R.
Fact
File Extension
CSV files use the .csv extension. Example: employee.csv, output.csv
Fact
Notepad & Excel
CSV files are plain text — you can create them in Notepad and open them in Excel. Both are TRUE.
R Function
read.csv()
Used to read/import a CSV file into R as a data frame.
data <- read.csv("employee.csv")
R Function
write.csv()
Used to write/export/create a CSV file from R.
write.csv(retval,"output.csv")
Data Frame
$ Operator
Access a column in a data frame using $.
data$salary — gets salary column.

data <- read.csv("employee.csv") # Access salary column with $ sal <- max(data$salary) # Get row(s) where salary equals max rval <- subset(data, salary == max(salary)) print(rval)

Dates that do NOT belong in subset(data, as.Date(start_date) > as.Date("2014-01-06")) are 2014-01-01 and 2014-01-02 — because they are before Jan 6, 2014.

XML — Extensible Markup Language
Questions 2, 3, 5, 6

What is XML?

XML (Extensible Markup Language) is a file format used to share structured data across systems, networks, and the web using standard ASCII text and tags — similar to HTML but for data, not display.
Definition
XML Full Form
Extensible Markup Language — not Extended, Extensive, or Executable.
Fact
XML → Data Frame
XML data CAN be parsed and converted into a data frame in R. Answer: true.
Fact
Data Sharing
XML shares file format and data on the World Wide Web, intranets, and elsewhere using standard ASCII text.
R Library
XML Package
Use library("XML") — NOT XLConnect. XLConnect is for Excel files.

Working Directory & File Handling
Questions 7, 8, 9, 10, 11, 12, 23, 29

What is a Working Directory?

The working directory is the default folder R uses to read and save files. If you run read.csv("employee.csv"), R looks for that file in the working directory.
Command
getwd()
Get/check the current working directory. Returns the active folder path.
Command
setwd()
Set/change the working directory.
setwd("C:/web/Sample")
Accepted
Forward Slash /
C:/MyDocuments/folder — forward slashes always work in R paths.
Accepted
Double Backslash \\
C:\\web\\Sample — double backslash also works as escape.
INVALID
Single Backslash \
C:\web\Sample — single backslash treated as escape character. WRONG!
RStudio
Environment Tab
R connects to Excel through the Environment tab in RStudio IDE.

Q12 Trick — "None Among Choices"

All four setwd() options in Q12 used forward slashes, making them all valid. So the answer is "none among choices" — meaning none of the given scripts are invalid/unaccepted.

Functions in R
Questions 21, 24, 25, 26, 32, 33, 34, 37, 38, 39, 42

What is a Function?

A function is a set of statements organized together to perform a specific task. R has built-in functions (like print, sum) and you can create your own (user-defined functions).
PartDescriptionOptional?
Function nameThe actual name stored in R environment — used to call itNo
ArgumentsPlaceholders / inputs — values passed into the functionYes
Function bodyThe code block inside { } — defines what the function doesNo
Return valueOptional output — R returns last expression even without return()Yes
Type
Built-in (In-built)
Functions already in R — called without defining first.
Examples: print(), max(), sum(), subset()
Type
User-Defined
Functions you create yourself using function(). Also called UDF.
Fact
Arguments are Optional
A function can have zero arguments:
hello <- function() { print("hi") }
Fact
Call with New Values
R can call functions with different argument values to get different results. Answer: true.

For Loop + Function Script (Q42) — Answer: a, ^, 7
# Function that squares numbers 1 to a new.function <- function(a) { # ← "a" is the argument for(i in 1:a) { # ← loop from 1 to a b <- i^2 # ← ^ means exponent (squared) print(b) } } # Call with 7 → prints squares of 1 through 7 new.function(7) # ← answer: 7
Q39 Trap: "We can also create and use our own functions referred to as in-built function." → FALSE. Functions you create are user-defined, not in-built/built-in.

Loops in R
Questions 20, 22, 27, 30, 36, 40, 41
While Loop
Runs while TRUE
Checks a condition. Keeps running as long as the condition is TRUE. Stops when it becomes FALSE.
While Loop
Infinite Loop
If the condition is always TRUE, the while loop runs forever → infinite loop.
Repeat Loop
No Condition in Header
repeat loop has no condition in its declaration. It runs indefinitely until stopped.
Repeat Loop
break to Stop
Use the break statement inside the loop body to exit a repeat loop.
